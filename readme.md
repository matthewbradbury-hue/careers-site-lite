# Oleeo Careers Homepage Design — Customer Version

This is a standalone, customer-facing version of the Oleeo microsite showcase, derived from the supplied final internal microsite package.

It retains the 5 live example tiles, 6 demonstration tiles, image assets and interactive before/after comparison. It replaces internal and sketch-style copy with concise customer-facing copy and adds indicative Lite and Full pricing.

## Run locally
Open `index.html` in a browser or serve the folder with any static web server.

## Netlify deployment
This is a static site and requires no build command. The publish directory is the folder containing `index.html` (Netlify publish path `.`). To deploy without GitHub, extract the ZIP and upload the website folder via Netlify's manual deploy interface.
